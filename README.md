# VisualStims

Visual stimuli made from the nervous system, by Nelu Radpour (Florida State University).
A sister site to [NeuroSims](https://nelurad.github.io/neurosims/): NeuroSims explains neuroscience, VisualStims is for looking at it.

Live at https://nelurad.github.io/visualstims/

Each stim is a folder with an `index.html` and a 900×600 `thumb.jpg`, listed on the root `index.html`.

| No. | Stim | What it is |
|---|---|---|
| 01 | [Melting Cortex](melting-cortex/) | Live-drawn pyramidal neurons, false-coloured by a WebGL shader, melting on scroll, with cursor-following contour lines. Technique inspired by metamorphic.com. |
| 02 | [Up the Canal](up-the-canal/) | A 3D ride up the spinal cord's central canal through the 4th ventricle, aqueduct, 3rd ventricle and into the lateral ventricle, with labelled structures outside the walls. |
